# HISTORY: CHARACTER BUILD — v3

중학교 역사 수행평가용 웹앱입니다. `Firebase Authentication + Cloud Firestore + GitHub + Vercel`을 기준으로 설계했습니다.

## v3 핵심 변화
- 인물의 전기를 여러 개 조사하지 않고 **대표 사건 1개**를 중심으로 학습합니다.
- 대표 사건 설명 2~3문장 + 인물과 사건의 연결 1~2문장 + **게임 재료가 될 역사적 사실 4개**만 작성합니다.
- 게임 요소는 최소 4개이며 기술/능력치를 자유롭게 혼용합니다.
- FACT 1~4를 각각 최소 한 번 게임 요소로 사용하게 하여 사건 학습과 캐릭터 설계를 직접 연결합니다.
- 첫 화면을 중학생 대상의 게임 퀘스트 UI로 재설계하고, 게임 카드 SVG 일러스트를 넣었습니다.
- 제목/UI에는 눈누에서 확인 가능한 **던파 비트비트체 v2**, 본문에는 **SUITE** 웹폰트를 사용합니다.
- 이미지 업로드는 Firebase Storage를 사용하지 않습니다. 브라우저에서 이미지를 작은 JPEG로 압축한 뒤 Firestore의 `submissionImages` 문서에 저장합니다.
- 학년도와 활동 ID를 모든 제출물에 저장하고 관리자 화면에서 **학년도/활동별 필터**를 제공합니다.
- Vercel `/api/grade` 서버리스 함수와 OpenAI API를 연결하면 관리자 화면에서 **AI 초벌평가(10점)** 를 바로 실행할 수 있습니다.
- AI 초벌평가 결과는 교사에게만 보이며 최종점수는 교사가 별도로 확정합니다.

## 학생 흐름
1. 상세 활동 설명 / 평가 기준 / AI 사용 규칙
2. 반·번호·이름·역사 인물
3. 대표 사건 1개 + 사건 관련 역사적 사실 4개
4. 사실을 선택해 기술/능력치 최소 4개 제작
5. 글 잠금 후 외부 AI 사이트에서 초상화 제작, 선택적으로 이미지 첨부
6. 최종 확인 및 제출

## 파일
- `index.html`: 학생 화면
- `student.js`: 학생 로직, 자동저장, 이탈/붙여넣기 기록
- `admin.html`, `admin.js`: 교사 관리자
- `config.js`: Firebase/학년도/활동/인물 설정
- `firestore.rules`: Firestore 보안 규칙
- `api/grade.js`: OpenAI API 초벌평가용 Vercel Function
- `SETUP_GUIDE.md`: 처음부터 배포까지 상세 설명

## 새 학년도/새 활동에 재사용하기
`config.js`의 아래 값만 바꾸면 됩니다.

```js
activity: {
  academicYear: "2027",
  id: "industrial-revolution-01",
  title: "산업혁명 역사 캐릭터 빌드",
  unitLabel: "산업혁명",
  referenceGuide: "..."
}
```

- 새 학년도: `academicYear` 변경
- 같은 학년도 새 수행활동: `id`를 반드시 다른 값으로 변경
- 관리자 화면에는 과거 데이터가 그대로 남고 학년도/활동 필터로 골라 볼 수 있습니다.

## Android 홈 버튼 주의
웹사이트는 Android 운영체제의 홈 버튼을 누르기 **전에** 확인창을 띄울 수 없습니다.
대신 이 앱은 화면이 숨겨지는 즉시 로컬 저장하고, STEP 1~4에서는 복귀할 때 화면 이탈 시간을 기록합니다.
브라우저/시스템 뒤로가기는 앱 자체 확인창을 띄우며, 새로고침/탭 닫기는 브라우저 기본 확인창을 사용합니다.
