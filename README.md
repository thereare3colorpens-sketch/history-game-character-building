# HISTORY: CHARACTER BUILD v4.7 — 채점 카드 + 이미지 보완 제출

이 패치는 **기존 수행평가 제출 데이터(submissions 등)를 수정하거나 삭제하지 않습니다.**

## 추가 기능

### 1) 교사용 `채점 카드로 보기`
- 학생 상세 화면 상단에 **📝 채점 카드로 보기** 버튼 추가
- 현재 학생 상세 패널 자체를 전체 화면 채점 모드로 전환하므로 기존 **AI 초벌평가 버튼/결과/교사 점수 기능이 그대로 작동**합니다.
- 최종 제출 후 보완된 이미지가 있으면 채점 카드 상단에 표시됩니다.
- `인쇄 / PDF` 버튼도 추가했습니다.

### 2) 최종 제출 직전 이미지 확인
- 학생이 `최종 제출`을 누르면 이미지 미리보기 확인 창을 한 번 보여줍니다.
- 이미지가 누락됐더라도 제출을 막지는 않습니다.
- `확인하고 최종 제출`을 누르면 기존 최종 제출 로직을 그대로 실행합니다.

### 3) 제출 완료 뒤 `초상화 보완 제출`
- 학생이 이미 최종 제출한 뒤에도 캐릭터 초상화만 다시 첨부할 수 있습니다.
- **글, FACT, 기술/능력치, 기존 제출 상태는 변경하지 않습니다.**
- 이미지는 브라우저에서 축소/압축 후, v4.6에서 이미 사용 중인 `stageExitLogs` 문서에 `postSubmitImage` 필드로 merge 저장합니다.
- 따라서 v4.6의 stageExitLogs 규칙을 이미 게시했다면 **새 Firestore rules 추가가 필요 없습니다.**
