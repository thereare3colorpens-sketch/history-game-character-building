# HISTORY: CHARACTER BUILD v4.8 업데이트

이번 패치는 기존 수행평가 데이터나 Firebase 구조를 변경하지 않습니다.

## 해결/추가 사항

### 1. 최종 제출 안정성
- 학생이 실제 최종 제출을 실행한 뒤 완료 화면이 나타나는지 최대 30초 확인합니다.
- 처리 중에는 화면 우하단에 `최종 제출 처리 중` 상태가 표시됩니다.
- 완료 전 창을 닫거나 새로고침하려 하면 브라우저 경고가 작동합니다.
- 30초 안에 완료가 확인되지 않으면 `다시 제출 시도` 안내를 표시합니다.
- STEP 6에 `제출 완료 표시를 반드시 확인`하라는 안내가 자동 추가됩니다.
- 기존 v4.7의 이미지 최종 확인/제출 후 이미지 보완 기능은 그대로 유지됩니다.

### 2. 교사용 채점 카드에서 이전/다음 학생
- 전체화면 채점 카드 상단에 `← 이전 학생`, `다음 학생 →` 버튼이 추가됩니다.
- 상세창을 닫고 목록에서 다시 학생을 고를 필요가 없습니다.

### 3. 게임형 교사 채점 화면
- 어두운 게임 HUD 스타일 + 고대비 텍스트로 재디자인했습니다.
- 학생 정보와 AI 상태가 상단 HUD에 표시됩니다.
- 본문 카드들은 가독성 중심으로 유지합니다.

### 4. AI 일괄 채점
- 관리자 상단에 `✨ AI 일괄 채점` 버튼이 추가됩니다.
- 현재 목록의 `제출 완료 + AI 미평가` 학생만 순차적으로 평가합니다.
- 한 번에 병렬 요청하지 않고 학생 한 명씩 처리하여 API 오류/과부하 가능성을 줄였습니다.
- 교사 최종점수는 변경하지 않습니다.
- 진행 중 중지할 수 있으며 실패 학생 수를 마지막에 알려줍니다.
